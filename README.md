# Interview Practice · 本地面试答题本

一个中文面试学习工具，提供即开即用的静态网页版，以及 FastAPI + SQLite 本地版。无须模型 API Key；网页版记录保存在浏览器，本地版记录保存在自己的电脑上。

## 在线体验

**[点击打开网页版 →](https://leoxfzhou.github.io/interview-practice/)**

网页版不需要下载、安装 Python 或启动服务，使用与本地版相同的 239 条公开题库和答题界面。

| | 网页版（GitHub Pages） | 本地版 |
| --- | --- | --- |
| 打开方式 | 点击上方链接 | 双击启动器或启动 Python 服务 |
| 方向与学习记录 | 当前浏览器的网站存储 | 本机 SQLite |
| 换设备/浏览器 | 不自动同步 | 由所在电脑的数据库决定 |
| 清理数据 | 清除网站数据会丢失记录；隐私窗口关闭后通常丢失 | 删除数据库会丢失记录 |

网页版的学习记录不上传服务器，访客之间互不影响；本地版已有进度不会自动迁移到网页版。浏览器需允许 JavaScript 和网站存储。若保存失败，页面会明确提示，不会假装已保存。建议同一时间只在一个标签页练习，以免不同标签显示的进度暂时不一致。下载题库仍需要网络，这不是离线安装应用。

网站由 GitHub 提供静态文件托管，因此访问请求仍会经过 GitHub；“不上传学习记录”不等于托管平台不接收网络访问请求。公开网站只含公开题库，不连接私人版或个人电脑。

## 功能

- **答题**：隐藏/显示答案，自评正确或错误，上一题修正评价，下一题跳过。
- **轮次练习**：同一轮不重复；正确题在 Reset 前不再出现。本轮结束后可选择复习错题，或练习未答题和错题。
- **题库**：完整展示参考答案；按方向分组，侧边目录跳转，支持全部/正确/错误筛选。
- **内容范围**：仅基础知识，或基础知识与面试题的综合学习。多方向按并集筛选；未选方向表示全部方向。
- **本地保存**：方向、内容范围、出现次数和评价持久化；首页显示全库统计，答题和题库显示所选范围统计。
- **Reset**：确认后清空全局练习记录，不删除题库或筛选设置。

## 题库适合哪些岗位？

主要面向 **大模型应用工程师（LLM Application Engineer）、AI 后端工程师，以及 RAG / Agent 应用开发相关岗位**。兼顾 Python 工程和 NLP / 深度学习基础，不是纯算法研究岗、数学笔试或所有后端岗位的完整题库。

内置 **192 道面试题 + 47 张基础知识卡，共 239 条、15 个方向**：

| 方向 | 相关内容 |
| --- | --- |
| Python 工程 | 生成器、异常、依赖管理、异步、类型与测试 |
| 数据结构与算法 | 复杂度、哈希表、二分、堆、图遍历与动态规划 |
| 计算机基础、网络与 HTTP | 状态码、超时、重试与网络调用边界 |
| PyTorch 与深度学习 | 张量、数据加载、训练、泛化、RNN、损失和评测 |
| NLP 与 Transformer | 词向量、Tokenization、BERT、注意力与模型架构 |
| 大模型应用 | Prompt、结构化输出、模型调用、流式响应和幻觉 |
| RAG 与评测 | 文档解析、切块、嵌入、混合检索、重排与质量评测 |
| Agent、工作流与 MCP | 工具调用、状态、循环限制、权限与协议边界 |
| FastAPI 与 AI 后端 | 依赖注入、接口契约、后台任务和错误处理 |
| 数据库、SQL、pgvector 与 Redis | 约束、索引、事务、向量查询、缓存与一致性 |
| Docker、部署与 CI/CD | 容器、持久化、健康检查、流水线和回滚 |
| 安全、可靠性与可观测性 | 身份与权限、提示注入、日志、限流、降级和容量 |
| 系统设计与工程场景 | 多租户、任务状态机、幂等、队列和架构取舍 |
| 求职表达与通用项目复盘 | 项目讲解、技术选型、指标证据和失败复盘的方法 |
| 扩展能力与岗位加试 | KV Cache、量化、LoRA、微调评测和推理服务 |

**仅基础知识**适合学习概念、机制、边界及代码示例；**综合学习**同时包含知识卡和面试问答，适合口述自测。多标签内容可能被多个方向筛选命中，但题库只按唯一主方向展示一次。

内容来自经过筛选、整理与校订的通用学习笔记和公开版独立编写的示例；不宣称全部内容均为原创。没有附带原始笔记、PDF、本机路径、个人项目材料、简历、实习记录或学习进度。通用项目复盘题只讲表达方法与假设场景，不代表作者真实项目、成果或性能指标。

代码用于说明概念：部分片段需要额外依赖、环境或配套服务，不能把教学配置直接用作生产方案。版本和数值输出不是最新版本承诺或跨设备保证。参考答案不替代官方文档，也不承诺覆盖所有面试知识点。

### 从早期示例版升级

原 42 条示例的稳定 ID 全部保留：35 条更新为更完整的同知识点内容，7 条独立示例继续保留。启动时按 ID 更新，不清空已有评价、次数、时间或方向设置；新增“求职表达”方向不会自动加入已有选择。发布数量及兼容 ID 列表见 `data/public_release.json`。

## 启动

需要 Python 3.10 或更新版本。首次安装依赖需要联网。

### macOS

双击 `start.command`，它会建立虚拟环境、安装依赖、选择本机端口，并在服务就绪后打开默认浏览器。

或者在仓库目录执行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python run.py
```

默认从 `127.0.0.1:8000` 开始寻找端口；同一个公开版已运行时复用，其他程序占用时递增端口。可用 `PORT=9000 python run.py` 指定起始端口。关闭浏览器不会关闭服务；在对应终端按 `Control-C` 停止。

### Windows / Linux

创建并激活 Python 虚拟环境、安装依赖后运行：

```bash
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

自行打开 `http://127.0.0.1:8000`。该方式不会自动换端口或打开浏览器。macOS 双击启动器不适用于 Windows/Linux；这两个平台尚未实际验收。

## 自己增加内容

面试题放在 `data/questions.json`，基础知识卡放在 `data/foundations/*.json`。每条内容的格式：

```json
{
  "id": "custom-python-001",
  "prompt": "你的通用问题",
  "answer": "参考答案，可使用分节标题和围栏代码块",
  "difficulty": "基础",
  "kind": "原理题",
  "stage": "S1",
  "topics": ["python"],
  "content_type": "interview",
  "primary_topic": "python",
  "source_name": "自行整理",
  "source_ref": "公开资料标题或自己定义的章节"
}
```

`content_type` 为 `foundation` 或 `interview`；主方向必须属于 `topics`。ID 唯一且更新时保持不变；题干不得重复。重启后按稳定 ID 更新答案并保留学习记录。删除 JSON 中的条目**不会自动删除**已存在的数据库记录。

JSON 文件是题库的唯一维护来源。运行 `python scripts/validate_bank.py` 可只读检查字段、重复题干、方向与隐私残留。旧示例生成器已改为兼容检查入口，不再覆盖扩充后的题库。

## 数据与安全边界

- SQLite 在第一次启动时自动生成，不随仓库发布；数据库、环境变量和运行缓存均被 Git 忽略。
- 默认仅绑定本机地址。没有账号、访问控制或公网部署保护，**不要直接绑定公网或做端口转发**。
- 不包含遥测、外部模型调用或第三方字体。安装依赖以及 Git 操作本身仍需要网络。
- 发布自己的改版前，应重新审查题库、来源字段、截图和 Git 历史；`.gitignore` 不会清理已经提交过的个人资料。
- 当前未指定开源许可证；公开可见不等同于授予任意再分发许可。

## 测试

在已安装依赖的环境中运行：

```bash
python -m unittest discover -s tests -v
```

测试使用临时数据库，不修改日常学习记录。前端不依赖构建工具。

浏览器数据层测试（需要 Node.js 22 或更新版本）：

```bash
node --test tests/browser-store.test.cjs
```

## 网页版构建与发布

同一份 JSON 题库供本地版和网页版使用；不要手工维护第二份题库。首次已配置 GitHub Pages，通过 `.github/workflows/pages.yml` 在 `main` 更新后自动测试、构建并发布。构建失败不会覆盖已上线版本。

本地预览（使用一个不存在或为空的输出目录）：

```bash
python scripts/build_pages.py --output dist-preview
python -m http.server 8080 --bind 127.0.0.1 --directory dist-preview
```

浏览器打开 `http://127.0.0.1:8080/`。请勿直接双击生成的 HTML：浏览器通常不允许它读取相邻 JSON 文件。重复构建时请指定另一个空目录；构建工具不会递归删除已有目录。

发布工具只打包首页、样式、脚本和经过校验的公开题库，不复制 SQLite、Python 源码、环境变量、测试数据或本地路径。静态资源使用内容哈希文件名，部署更新不会重置浏览器中按稳定题目 ID 保存的评价。不要把私人内容加入这个公开仓库。

如要在自己的 Fork 启用网站，在仓库 Settings → Pages 中选择 GitHub Actions，并运行 Publish interview practice 工作流；README 在线链接需改成自己的地址。发布机制参考 [GitHub Pages 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。
